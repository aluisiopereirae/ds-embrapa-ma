Guia do Assistente de Dados

🤖 O que é este assistente?

Um chat com Inteligência Artificial (RAG) — Retrieval-Augmented Generation — que lê e analisa em tempo real todos os dados cadastrados nesta plataforma e responde perguntas específicas sobre eles.

A cada pergunta, o contexto completo dos dados (registros, sistemas, indicadores) é enviado ao modelo de IA junto com sua mensagem, permitindo respostas precisas e atualizadas.

⚙ Como configurar

1

Acesse console.anthropic.com e crie uma conta ou faça login.

2

Vá em API Keys → Create Key e copie a chave gerada (começa com sk-ant-...).

3

No chat, clique em ⚙ Configurar chave de API, cole a chave e salve. Ela fica armazenada apenas no seu navegador — nunca é enviada a terceiros.

4

Pronto! Comece a fazer perguntas. O modelo usado é o Claude Haiku — rápido e econômico para análise de dados.

📊 O que o assistente analisa

O assistente tem acesso completo a:

• DB principal — todos os registros de unidades produtivas (ILPF, ILP, SAF, Apicultura, Meliponicultura, Piscicultura, Fruticultura, Roça, Sisteminha, Extrativismo)

• Indicadores — área, renda, balanço de carbono, sequestro, diversidade de espécies, temperatura, precipitação

• Localização — município, mesorregião, bioma, altitude

• Datasets complementares — ILPF_DATA, SAF_DATA, PISC_DATA, APIC_DATA, FRUTICULTURA_DATA, EXTRAT_DATA e outros

💬 Exemplos de perguntas — clique para usar

⚡ Dicas de uso

• Seja específico — quanto mais detalhada a pergunta, melhor a resposta.

• Use Shift + Enter para quebrar linha; Enter envia a mensagem.

• O chat lembra as últimas 12 mensagens — você pode fazer perguntas de acompanhamento.

• Clique em 🗑 para reiniciar a conversa a qualquer momento.

• Se a chave de API expirar, clique em ⚙ para inserir uma nova.
